# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

## Reporting a vulnerability

Please do not open public issues for security problems. Email
security@learnsphere.dev with a description, reproduction steps and the
affected component. You can expect an acknowledgement within 3 business days
and a status update within 10 days.

We follow coordinated disclosure: please give us a reasonable window to ship a
fix before publishing details. Reporters are credited in the changelog unless
they prefer to remain anonymous.

## Scope

In scope: the API, web app, worker, media service and recommender in this
repository. Out of scope: third-party dependencies (report upstream) and
social-engineering attacks.
