# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project adheres
to [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added
- Route-level loading and error boundaries for the web app.
- Configuration validation and HLS rendition ladder in the media service.

## [1.0.0] - 2024-03-28

### Added
- Forum thread voting and migration `20240320000000_forum_votes`.
- Completion certificates rendered by the worker service.
- Course recommendations from the Python recommender service.
- Adaptive-bitrate transcoding in the Go media service.

### Changed
- Dashboard now shows recommended courses alongside enrollments.

## [0.2.0] - 2024-02-15

### Added
- Certificates table and issuance endpoints.
- Quiz grading with partial credit.

## [0.1.0] - 2024-01-01

### Added
- Initial release: courses, lessons, enrollments, progress tracking and authentication.
